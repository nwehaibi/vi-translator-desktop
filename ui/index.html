Game profile

A profile holds a game's read areas, how its translations look, and the game's own pages it translates. Built-in profiles can't be changed: make a copy to adjust one.

Game pages

The game's own pages that get a hand-made translation, in the game's look.

Snapshot

Translates all the text on the game's picture at once and shows it over the picture, like a translated photo: menus, the map, the phone, a car's stats.

Snapshot service

Most GTA VI lines are already translated and reviewed, and are shown instantly. Only lines not found there go to the translator chosen below. Keep this on: with it off, every line waits for the translator and translations come much slower.

Language

Translation service

Keys are saved only on this PC, in the app's settings file.

Translation memory

Remembers every translated line and reuses it instantly the next time it appears — no translator call, and no waiting for the line to settle.

Read areas

Each area is read separately. Position and size are a percentage of the window, so they stay right if the window is resized.
